# Getting started with threews-avatar-mcp

MCP server for three.ws 3D avatars by three.ws — render a live, rotatable on-chain avatar inline (interactive MCP App), get a paste-anywhere embed iframe, or fetch avatar metadata. Free, no API key.

## Install

```bash
npm install @three-ws/avatar-mcp
```

## Verify the install

Clone the repository and run its checks to confirm everything works on your machine:

```bash
git clone https://github.com/nirholas/threews-avatar-mcp.git
cd threews-avatar-mcp
```

Available commands:

| Command | Runs |
|---|---|
| `npm run build` | `node app/build.mjs` |
| `npm run start` | `node src/index.js` |
| `npm run test` | `node --test` |
